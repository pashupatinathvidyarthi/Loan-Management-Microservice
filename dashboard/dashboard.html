How the async credit check works

Submitting a loan below does not decide it synchronously. The API commits it to Postgres as PENDING, publishes a Kafka event, and returns immediately. A separate consumer picks the event up moments later and updates the status. Submit a loan from the Loan Applications tab to watch this happen in real time below.
